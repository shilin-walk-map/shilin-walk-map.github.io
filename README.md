# Shilin Night Market walking map

Multilingual food map with zoom, shop and landmark details, Google Maps / Apple Maps walking directions, and MRT / bus information.

Website: https://shilin-walk-map.github.io/

Language pages: [ja](https://shilin-walk-map.github.io/ja/) · [zh-hant-hk](https://shilin-walk-map.github.io/zh-hant-hk/) · [ko](https://shilin-walk-map.github.io/ko/) · [en-us](https://shilin-walk-map.github.io/en-us/) · [zh-hans](https://shilin-walk-map.github.io/zh-hans/) · [en-ph](https://shilin-walk-map.github.io/en-ph/) · [en-sg](https://shilin-walk-map.github.io/en-sg/) · [vi](https://shilin-walk-map.github.io/vi/) · [th](https://shilin-walk-map.github.io/th/) · [en-my](https://shilin-walk-map.github.io/en-my/) · [en](https://shilin-walk-map.github.io/en/) · [zh-hant](https://shilin-walk-map.github.io/zh-hant/)

## Hosting

GitHub Pages organization home: `shilin-walk-map/shilin-walk-map.github.io`, publish the `main` branch, root folder. Static HTML/CSS/JavaScript; no server or API key is required. Each edition has pre-rendered localized text, canonical URL, and reciprocal language links.

Paper maps: 12 one-page A4 landscape PDFs are available through the download button in each language edition. All QR codes link to https://shilin-walk-map.github.io/. No printable PNG downloads are provided.

Map locations are illustrations. Walking directions open in the selected map service. Transport schedules have a review date and official source links on the website.

Font licenses are included under `assets/webfonts/`. Third-party names, logos, and photographs retain their respective rights; this repository does not grant a blanket asset license.
