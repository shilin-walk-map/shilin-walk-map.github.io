如何前往士林夜市

從台北車站出發

從 R10 台北車站搭淡水信義線（紅線），往淡水／北投方向，到 R15 劍潭站下車，使用1號出口。

從西門町出發

從 G12 西門站搭松山新店線（綠線）往松山，到中山站轉紅線往淡水／北投，在 R15 劍潭站下車，使用1號出口。

首末班捷運、218公車，以及回台北車站或西門町的資訊，請看互動地圖的交通區塊，內附官方時刻表連結。

常見問題

去士林夜市要在哪個捷運站下車？

本圖散步路線由 R15 劍潭站1號出口開始。夜市名稱是士林，但這條路線的出發站是劍潭站。

紙本地圖可以列印嗎？

可以，每個版本都有一頁 A4 橫式 PDF。QR Code 會開啟多語線上地圖。列印時選橫式、100%或實際大小。

如何導航到美食店家？

開啟互動地圖，點選店家編號，確認中文店名與地址後，選擇 Google 地圖或 Apple 地圖，即可在該服務開啟步行導航。

哪裡有洗手間？

地圖已標示洗手間圖示。店內洗手間請先詢問工作人員，使用條件依場所而定。

地圖整理方式與資料依據

排列順序為本地圖的編輯安排，不是官方人氣排名或旅客票選。各版本可能有不同店家與順序。中文店名方便對照現場招牌與地圖搜尋；簡短品項說明包含編輯翻譯，有取得參考用字與連結的部分會列出依據。

地址沿用先前已確認的導航目的地資料，不代表所有店家都曾由我們獨立實訪。營業時間、價格與供應狀況不作推測，出發前請以店家與交通機關官方資訊為準。
